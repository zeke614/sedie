# 🌍 sedie

**sedie** is a fast, free, and highly secure currency converter web app. Originally built with React, now migrated to Next.js, TypeScript, and Tailwind CSS, it offers instant conversion between 150+ global currencies, interactive historical data, and supports multiple languages.

## ✨ Features

- ⚡ **Server-Side Rendered (SSR)** for blazing fast initial loads and optimized SEO.
- 🔒 **Secure API Proxy Architecture:** External API keys are strictly hidden on the backend using Next.js Route Handlers.
- 📱 **Responsive Design:** Optimized for seamless use across all devices.
- 📊 **Historical Exchange Graphs:** Interactive charts showing currency trends over time.
- 🌗 **Seamless Dark Mode:** Hydration-safe theme switching.
- 🌐 **Multilingual support:** English, German, French, Spanish, Italian, and more.
- 🌎 **Smart Geolocation:** Auto-detects your local currency based on IP address routing.
- 🕒 **Relative Time Tracking:** Shows exactly when rates were last fetched (e.g., “Updated 3 minutes ago”).

## 🚀 Tech Stack

- **Next.js (App Router)** – Full-stack framework & Server Components
- **React + TypeScript** – UI and type safety
- **Tailwind CSS** – Styling
- **Recharts** – Interactive historical data visualization
- **Framer Motion** – Fluid animations
- **i18next** – Localization
- **Open Exchange Rates API** – Real-time and historical currency data
- **IPInfo API** – For location-based currency detection
